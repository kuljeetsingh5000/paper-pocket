    # 📎 Paper Pocket

    A tiny desktop pocket I built for keeping files, snippets, prompts, and quick checklists handy.

    ## ✨ What it does

    - 📎 Drag & drop files into a floating desktop pocket
    - 📝 Save quick snippets, prompts, and notes
    - 🔎 Search saved items
    - 📤 Drag stored files back out
    - ☑️ Turn pasted tasks into a checklist
    - ◐ Track tasks as To Do → Doing → Done
    - 🎨 Use a custom character
    - 🖥️ Stay on top of your desktop

    ## 🛠️ Built with

    - React
    - Electron
    - JavaScript
    - CSS
    - Vite

    ## 🚀 Run locally

    ```bash
    npm install
    npm run build
    npm start

💡 Why I built it

I wanted to experiment with building a small desktop utility rather than another browser-based application.

The idea was simple:

"What if I had a tiny pocket on my desktop where I could throw things I don't want to lose?"

That turned into Paper Pocket.

Along the way, I experimented with Electron window management, React UI, drag-and-drop, local file storage, IPC communication, custom character controls, and a lightweight taskification system.
